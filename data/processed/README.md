# Processed data

This folder is scratch space for artefacts produced by **your** pipeline — for example:

- a normalised `products.json` that joins catalogue, categories, brands, inventory, descriptions and review aggregates;
- a search index (e.g. `inverted-index.json`) for Day 05;
- benchmark output for Day 06.

Nothing in this folder is committed except this README (see `.gitignore`).

## Suggested convention

```text
data/processed/
├── products.normalised.json
├── index/
│   └── inverted-index.json
└── benchmarks/
    └── day-06.json
```

Keep the outputs reproducible: a script in the challenge folder should be able to delete and rebuild them. If an artefact is generated by `npm run ...`, say so in the challenge README.

Do not copy `data/raw` into this folder. Do not commit large outputs.
